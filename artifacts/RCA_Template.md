# Troubleshooting OS — RCA Template

## Context
Describe the system, expected behavior, and environment.

## Problem
Concise summary of the failure.

## Observed Symptoms
List measurable indicators.

## Evidence Collected
| Observation | Evidence | Conclusion |
|------------|----------|------------|

## Hypotheses
List all possible causes.  
Mark each as:
- ❌ Rejected  
- ⚠️ Partially Correct  
- ✅ Confirmed  

## Tests Performed
Describe verification steps and outcomes.

## Root Cause

## Resolution

## Lessons Learned

## Future Prevention
